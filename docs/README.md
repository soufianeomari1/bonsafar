# BonSafar docs

Planning docs are in French (written by the builder). Code and judge-facing material are in English.

| File | What it holds | Read it when |
|---|---|---|
| `battuta-contexte.md` | Source of truth: hackathon rules, judging, models, data, audiences, decisions log | Always, first |
| `meta-model-api.md` | Verified facts about the Meta Model API (IDs, endpoints, prices, open questions) | Any AI code |
| `parcours-et-interfaces.md` | Every screen, design tokens, 9 signature animations, haptics, data model | Any UI or data work |
| `plan-de-dev.md` | The 5 build blocks, schedule, what to cut if late | Planning |
| `demo-et-mode-jury.md` | Judges' 60-second path, 3 scenarios, robustness, video script, README template | Block 5, README |
| `prompts/bloc-1.md` to `bloc-5.md` | The exact prompt of each build block, with its done criteria | At the start of each block |

Mockups: `design/maquettes/png` (16 screens, 2x) and `design/maquettes/html` (exact CSS values, reference only).

Screen numbering (00 to 10b, J1, J2) is shared by the docs, the mockups and the prompts.
