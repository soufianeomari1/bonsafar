# Maquettes BonSafar (V1, 3 nov. 2026)

À copier dans le dépôt sous `design/maquettes/`.

- `png/` : le rendu de chaque écran (2x). C'est ce qu'on glisse dans Cursor : il lit les images.
- `html/` : la source de chaque planche, avec les valeurs exactes (couleurs, tailles, espacements, animations CSS). Ces fichiers viennent de l'outil de maquettes et ne s'ouvrent pas seuls dans un navigateur : ils servent de référence, pas de code à réutiliser.

Numérotation (voir docs/parcours-et-interfaces.md, section 9) :
- 00 Connexion · 01a Profil, langue · 01b Profil, tes papiers · 01c Carte de confiance
- 02 Accueil · 03 Vocal · 04 BonSafar a compris
- 05 Plan de vol · 06 Résultat · 07 Fiche forfait (écran long) · 08 Prêt à partir
- 09 Vérifie et continue · 10 Dossier · 10b Affiche Rihla
- J1 Mode jury (anglais) · J2 Desktop Under the hood (anglais)
